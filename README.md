### 👨‍💻 About Me

I am a software developer currently studying at **École 42**, with a strong focus on **C, C++**, and **low-level system programming**. My journey is all about understanding how things work under the hood by building core tools, system architectures, and graphical applications entirely from scratch, without relying on standard libraries.

*   🌱 **Core Focus Areas:** 
    *   Strict memory management and building deep copy mechanisms.
    *   Object-Oriented Programming with strict adherence to the **C++98 standard**.
    *   System calls, process management, and custom shell implementations.
    *   Algorithmic problem solving and low-level graphical rendering (e.g., Raycasting).
*   💻 **Development Environment:** Predominantly working in terminal environments on Linux (Ubuntu) and WSL, heavily utilizing Makefiles and Bash.
